# jellyfin-linux-server
## Project Overview

This project documents the deployment and administration of a self-hosted Jellyfin media server running on Ubuntu Server.

The goal of the project is to gain hands-on experience with Linux server administration, networking, security, service management, troubleshooting, and hardware acceleration.

## Current Server Hardware

- **System:** HP EliteDesk 800 G5 Desktop Mini
- **Processor:** Intel Core i5-9500T
- **CPU Cores:** 6 cores / 6 threads
- **Memory:** 16 GB RAM
- **Storage:** 256 GB NVMe SSD
- **Integrated GPU:** Intel UHD Graphics 630
- **Network:** Wired Ethernet

## Software

- **Operating System:** Ubuntu Server 24.04.4 LTS
- **Kernel:** Linux 6.8.0-136-generic
- **Media Server:** Jellyfin Server 10.11.11
- **Firewall:** UFW
- **Service Management:** systemd

## Skills Demonstrated

- Linux server administration
- Linux command-line usage
- Network configuration and troubleshooting
- Firewall configuration
- SSH remote administration
- Linux service management with systemd
- User and group permissions
- GPU device configuration
- Intel hardware-acceleration preparation
- Server troubleshooting and verification

## Project Status

The Jellyfin server is operational and accessible over the local network. Hardware acceleration has been prepared using the Intel UHD Graphics 630. Actual hardware transcoding will be tested once media is added to the server.
